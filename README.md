# PHP Clinic Management System

A simple clinic management system built with PHP, MySQL, and Bootstrap.

## Features

* Doctor, Patient, Pharmacist, and Admin login
* Patient management
* Drug management
* Assign drugs to patients
* Role-based access
* CSRF protection
* Prepared statements
* Responsive design

## Technologies

* PHP
* MySQL
* Bootstrap 5
* HTML
* CSS

## Run the Project

1. Put the project inside the XAMPP `htdocs` folder.
2. Start Apache and MySQL.
3. Import `database/hospital_rebuilt.sql` using phpMyAdmin.
4. Open the project in the browser.

Example:

`http://localhost/PHP-Clinic-Management-System/View/login.php`
